# Figures

Simpan gambar, diagram, dan aset visual skripsi di folder ini. Gunakan nama file deskriptif tanpa spasi, misalnya `alur_penelitian.png`.

Untuk edisi bahasa Inggris, simpan versi gambar berlabel Inggris di `figures/english/` dengan nama file yang sama. Edisi Inggris mencari gambar di sana lebih dahulu, lalu di folder ini.
